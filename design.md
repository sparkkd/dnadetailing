# Dn'A Detailing — Design System

Brand: Dn'A Detailing, a high-end car detailing business.
Reference copied: Apple product-page pattern (e.g. apple.com hero/feature pages) —
big confident type, full-bleed hero media, generous negative space, one thought per
section, alternating dark/light sections, pill buttons, soft fades between sections.

## Colors
- `--ink: #0A0A0B` — near-black background for dark sections
- `--paper: #F6F5F1` — warm off-white background for light sections
- `--ink-soft: #1C1C1F` — card surfaces on dark
- `--paper-soft: #EDEBE4` — card surfaces on light
- `--text-on-dark: #F6F5F1`
- `--text-on-dark-mute: #A8A6A0`
- `--text-on-light: #0A0A0B`
- `--text-on-light-mute: #5B5955`
- `--accent: #C9A227` — brushed-brass/gold, the one accent color (precision + luxury)
- `--accent-soft: #E7D9A6`

## Type
- Display face: "Inter Tight" (fallback Inter, -apple-system)
- Body face: "Inter"
- Letter spacing on display: -0.03em
- Scale: hero 84px/0.98, h2 48px/1.05, h3 28px/1.1, body 18px/1.6, caption 14px/1.4
- Weights: display 650–700, body 400–500

## Shape
- Radius: 28px on large cards/media frames, 999px (pill) on buttons
- Buttons: pill, 1px hairline border on dark, solid accent on primary CTA
- No hard section borders — sections fade into each other via a 120px gradient overlap

## Section order (page laws)
1. Hero — live 3D showpiece (Level 1)
2. Scroll film, own section (Level 2)
3. Services / stills grid (Level 2 stills, living loops)
4. Living motion graphic — "how a detail works" (Level 3)
5. Closing CTA (calm, dark)

## Layout rule
Copy left, visual right, on every two-column section. Never text over busy footage.
